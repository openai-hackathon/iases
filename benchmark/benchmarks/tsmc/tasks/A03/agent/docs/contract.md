# A03 Public API and data contract

`impacted_lots(steps,events)`. steps=(lot_id,machine_id,enter,exit); events=(event_id,machine_id,start,end). Timestamps require an offset. Intervals are half-open [start,end); a match requires the same machine and an intersection of positive duration. Touching endpoints and zero-length intervals do not match. Any reversed interval raises ValueError, even if that row would not join. Null end values are not supported. event_id is unique or replays the identical event. Output exactly one row per lot, with unique lexicographically sorted event_ids; sort lots lexicographically by lot_id as well. Duplicate lot steps do not change results. Preserve all evidence, not just one event. Do not mutate inputs. This synthetic temporal/spatial association does not establish a real manufacturing root cause.

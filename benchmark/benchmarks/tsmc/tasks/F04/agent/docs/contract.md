# F04 Public API and data contract

`evaluate(reading,sensors)`: an unknown sensor_id raises ValueError. Pressure uses Pa as the base unit: kPa*1000, MPa*1000000, mbar*100. Temperature uses C: K-273.15, (F-32)*5/9. Dictionary high values are already in base units. Strictly greater means ALARM; equality means OK. value=None means MISSING before checking units. Unsupported units, dimensional mismatch, unparseable numbers, bool and NaN/Inf mean INVALID. INVALID/MISSING have value_base=null. Convert valid numbers or numeric strings to float. Negative values are allowed synthetic inputs; do not infer additional physical-validity constraints. Output {sensor_id,status,value_base}, with numeric absolute tolerance 1e-9. Do not mutate inputs. This is not a process safety alarm system.

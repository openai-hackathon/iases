# F02 Public API and data contract

API: `Registry(records)`, `apply(event)->bool`, `allowed(machine_id, product_id, step_id)->bool`. A qualification key is the three-field tuple; version is a nonnegative integer and valid is a bool. A newer version replaces the old one; an older version is ignored. The same version with the same valid value is a replay; conflicting valid values at the same version raise ConflictError without changing state. A missing qualification returns False, but a later addition must take effect immediately. Queries after any update must reflect the current version, whether implemented with a cache or direct lookup. Defensively copy input events. CLI actions contain query or update; output only query results. This version covers a single-process Registry, not distributed cache consistency.

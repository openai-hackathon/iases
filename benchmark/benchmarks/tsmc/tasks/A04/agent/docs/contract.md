# A04 Public API and data contract

`update(state,batch)` returns new state; see public expected output for initial_state and state fields. offset is a unique nonnegative sequence within one ingestion partition. Rows may be unordered within a batch, but the delivered prefix is complete across batches; offset<=last_offset is replay. Event times may arrive late or be equal and must not exclude a new offset. watermark is diagnostic only: the maximum observed event time in UTC isoformat, not a discard threshold. event_id globally identifies a measurement and may replay at a new offset with the same payload. Preserve seen across checkpoint JSON roundtrips for deduplication. Count/sum independently per machine; every new offset advances the cursor even for a replayed event_id. value must be finite numeric data; invalid values raise ValueError. Do not mutate input state. Indefinite seen retention is an explicit choice for this small fixture, not a large-scale retention design. Previously undelivered new events with offset<=cursor and cross-partition merging are outside scope.

# R04 Public API and data contract

`WorkerPool(limit)` is a local analysis slot pool for one asyncio event loop. limit is a positive integer, excluding bool. `execute(job)` waits for a slot and invokes a zero-argument callback returning an awaitable; return its successful result unchanged and propagate errors and CancelledError unchanged. Only a successful acquire requires cleanup, exactly once. Cancellation while waiting must not release another job's slot. active counts current slot owners, free_slots=limit-active, and peak records the maximum ownership count; counters never exceed limit or become negative. A callback incorrectly returning a non-awaitable must still release its slot. Tests use await asyncio.sleep(0) only to yield to the event loop, not to simulate elapsed work. This is the task's factory analysis executor, not the agent inference router. Cross-event-loop and cross-process slot sharing are outside scope.

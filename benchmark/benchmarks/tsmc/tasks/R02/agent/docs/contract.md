# R02 Public API and data contract

`reserve(path,request_id,machine_id,units=1,hook=None,fail_after_insert=False)` uses one SQLite database. Return True for acceptance and False for insufficient capacity. An unknown machine, nonpositive/noninteger units or conflicting request_id raises ValueError; units excludes bool. Replaying the same request_id+machine+units returns True without consuming more capacity; the same ID with different content conflicts. Committed units must never exceed machine capacity. hook is an optional public synchronization point called once per valid invocation before the capacity-decision critical section; do not hold a write lock while waiting for hook. Do not remove hook to evade concurrency tests. fail_after_insert raises InjectedFailure after insertion but before commit and must roll back completely. release returns True when deleting an existing reservation and False for unknown or repeated releases. Support separate connections/threads in one process, without Python globals holding capacity across connections; any correct locking strategy is acceptable. Cross-machine databases are not tested.
